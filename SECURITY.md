# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release.
Older versions are not actively maintained.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/kongesque/line-cli/security/advisories/new).

Do not disclose unfixed vulnerabilities in public issues.

Include:

- The affected LINE CLI version and operating system
- Steps to reproduce the issue, preferably using synthetic data
- The potential security impact

Do not include LINE passwords, session tokens, private keys,
or private conversation content.

Reports will be reviewed to determine the impact and appropriate fix.

For encryption behavior, limitations, and recorded validation, see the
[security model and validation reference](docs/SECURITY.md).
