# LINE CLI: ใช้งานบัญชี LINE ส่วนตัวผ่านเทอร์มินัล

ภาษาไทย | [English](README.md)

**LINE CLI** คือไคลเอนต์แบบบรรทัดคำสั่งอย่างไม่เป็นทางการสำหรับบัญชี LINE
ส่วนตัว ช่วยให้คุณอ่านและส่งข้อความ แชร์ไฟล์ ตอบกลับ แสดงความรู้สึก
ยกเลิกข้อความที่ส่ง ติดตามเหตุการณ์แบบเรียลไทม์ รวมถึงทำงานร่วมกับสคริปต์
และเวิร์กโฟลว์ของ AI agent ผ่าน JSON ได้จากเทอร์มินัล

LINE CLI ต่างจากเครื่องมือที่ใช้ LINE Messaging API ตรงที่ทำงานกับบัญชี LINE
ส่วนตัวของคุณโดยตรง ไม่ใช่บัญชีบอต

LINE CLI รองรับ macOS, Linux และ Windows พร้อมการเข้ารหัสจากต้นทางถึงปลายทาง
ด้วย Letter Sealing และระบบจัดเก็บข้อมูลรับรองของระบบปฏิบัติการ

> [!IMPORTANT]
> LINE อนุญาตเซสชันแบบ Chrome ได้ครั้งละหนึ่งเซสชัน การลงชื่อเข้าใช้ด้วย `line`
> อาจแทนที่เซสชันเดิมของส่วนขยาย LINE สำหรับ Chrome หรือไคลเอนต์อื่นที่ใช้
> เซสชันแบบ Chrome โดย CLI จะจัดเก็บได้หนึ่งบัญชีต่อผู้ใช้ระบบปฏิบัติการ

## ความสามารถ

- ใช้บัญชี LINE ส่วนตัวของคุณได้โดยตรงจากเทอร์มินัล
- ค้นหารายชื่อติดต่อ กลุ่ม และบทสนทนา
- อ่านประวัติข้อความล่าสุด
- ส่งข้อความแบบบรรทัดเดียวและหลายบรรทัด
- ส่งไฟล์ทั่วไปขนาดไม่เกิน 20 MiB
- ตอบกลับข้อความเดิม
- เพิ่มหรือลบการแสดงความรู้สึกมาตรฐาน
- ยกเลิกข้อความที่คุณส่ง
- รับเหตุการณ์ LINE แบบเรียลไทม์ในรูปแบบ NDJSON
- แสดงผลเป็น JSON สำหรับ shell script และระบบอัตโนมัติ
- ปกป้องเซสชันที่บันทึกไว้ด้วยที่เก็บข้อมูลรับรองของระบบปฏิบัติการ
- ใช้การเข้ารหัส Letter Sealing เมื่อบทสนทนารองรับ

## ติดตั้ง LINE CLI

### macOS ด้วย Homebrew

```sh
brew install kongesque/tap/line-cli
```

Homebrew จะสร้างรีลีสที่ติดแท็กจากซอร์สโค้ดและติดตั้งคำสั่ง `line`
วิธีนี้ช่วยหลีกเลี่ยงคำเตือนจาก Gatekeeper ที่ปรากฏเมื่อติดตั้งไฟล์ซึ่งดาวน์โหลด
จากเบราว์เซอร์และไม่มีลายเซ็น

หากต้องการอัปเกรดในภายหลัง ให้ใช้คำสั่ง:

```sh
brew upgrade line-cli
```

### Linux และ Windows

ดาวน์โหลดไฟล์สำหรับระบบปฏิบัติการและสถาปัตยกรรมของคุณจาก
[GitHub Releases](https://github.com/kongesque/line-cli/releases/latest)
ตรวจสอบความถูกต้องด้วยไฟล์ `SHA256SUMS` ที่แนบมาก่อนติดตั้ง `line` หรือ
`line.exe`

ไฟล์ไบนารีของรีลีสยังไม่มีลายเซ็น ผู้ใช้ macOS ควรติดตั้งผ่าน Homebrew
ส่วนไฟล์ไบนารีสำหรับ macOS ที่ดาวน์โหลดผ่านเบราว์เซอร์จะต้องอนุญาตด้วยตนเองใน
Privacy & Security

### สร้างจากซอร์สโค้ด

ต้องติดตั้ง Git และ Go 1.26 ขึ้นไป:

```sh
git clone https://github.com/kongesque/line-cli.git
cd line-cli
./install.sh
line help
```

ดูข้อกำหนดเกี่ยวกับ keyring บน Linux วิธีใช้ PowerShell บน Windows
การตั้งค่า PATH และการสร้างด้วยตนเองได้ที่
[คู่มือการติดตั้ง](CLI.md#build)

## ใช้งาน LINE จากเทอร์มินัล

บัญชี LINE ของคุณต้องตั้งค่าอีเมลและรหัสผ่านไว้ การเข้าสู่ระบบเป็นแบบโต้ตอบ
และต้องยืนยันจากโทรศัพท์ของคุณ

```sh
line login
line whoami
line chats
line messages "Family group" --limit 10
line send "Alice" --text "Hello!"
```

เมื่อระบุชื่อเป็นอาร์กิวเมนต์ ชื่อนั้นต้องตรงกันทุกตัวอักษรและไม่ซ้ำกับชื่ออื่น
หากต้องการเลือกแชตแบบโต้ตอบ ให้เรียกคำสั่งโดยไม่ระบุเป้าหมาย:

```sh
line messages
line send
line react
line unsend
```

ตัวอย่างการใช้งานทั่วไปอื่น ๆ:

```sh
line send "Alice" --file ./report.pdf
line send "Alice" --text "Sounds good" --reply-to MESSAGE_ID
line react "Alice" --message MESSAGE_ID --reaction love
line download "Alice" --message MESSAGE_ID --output ./received.pdf
```

ใช้ `line COMMAND --help` เพื่อดูตัวเลือกและตัวอย่างของแต่ละคำสั่ง

## JSON และระบบอัตโนมัติ

```sh
line chats --search "Family" --json
line messages "Alice" --limit 20 --json
line send "Alice" --stdin < message.txt
line watch --json > events.ndjson
```

ข้อมูล JSON จะถูกส่งไปยัง stdout ส่วนข้อมูลวินิจฉัยจะถูกส่งไปยัง stderr
โปรดถือว่าข้อความและเหตุการณ์ที่ส่งออกเป็นข้อมูลบทสนทนาส่วนตัว

การดำเนินการที่แก้ไขข้อมูลบนเซิร์ฟเวอร์จะถูกลองเพียงครั้งเดียวและจะไม่มีการลองซ้ำ
โดยอัตโนมัติ หากไม่ได้รับผลตอบกลับจากการส่งข้อความหรืออัปโหลดไฟล์
ให้ตรวจสอบใน LINE ก่อนลองอีกครั้งเพื่อหลีกเลี่ยงข้อมูลซ้ำ

## ความปลอดภัยและความเป็นส่วนตัว

LINE CLI ใช้ Letter Sealing เมื่อบัญชีและบทสนทนารองรับ หากไม่มีคีย์
คีย์ไม่ถูกต้อง หรือเครือข่ายขัดข้อง การส่งข้อความที่เข้ารหัสจะไม่เปลี่ยนไปส่ง
เป็นข้อความธรรมดาโดยไม่แจ้งให้ทราบ ผลลัพธ์ของคำสั่งส่งข้อความจะระบุว่ามีการ
เข้ารหัสหรือไม่

รหัสผ่านของคุณจะไม่ถูกบันทึก เซสชันจะได้รับการปกป้องโดยระบบปฏิบัติการ:

| แพลตฟอร์ม | ที่เก็บข้อมูลรับรอง |
| --- | --- |
| macOS | Keychain |
| Linux | ไฟล์เซสชันที่เข้ารหัสด้วย AES-GCM โดยเก็บ wrapping key ไว้ใน Secret Service |
| Windows | DPAPI ของผู้ใช้ปัจจุบัน |

LINE CLI สร้างขึ้นบนโปรโตคอลแบบเดียวกับไคลเอนต์ LINE สำหรับ Chrome
การเปลี่ยนแปลงฝั่งเซิร์ฟเวอร์อาจส่งผลต่อความเข้ากันได้

## ข้อจำกัดในปัจจุบัน

- บันทึกได้หนึ่งบัญชีต่อผู้ใช้ระบบปฏิบัติการ
- อ่านได้เฉพาะประวัติล่าสุด สูงสุด 100 ข้อความต่อครั้ง
- รองรับเฉพาะการรับส่งไฟล์ทั่วไป ยังไม่รองรับสติกเกอร์หรือข้อความสื่อชนิดเฉพาะ
- การอ่านข้อความจะไม่ทำเครื่องหมายว่าอ่านแล้ว
- เส้นทางการทำงานบางส่วนของโปรโตคอลยังต้องผ่านการทดสอบกับระบบจริงเพิ่มเติม
